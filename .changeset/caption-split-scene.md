`splitToFit()` (on `@glissade/scene/type`) — the measured, band-aware answer to "this text is too long for the band". Breaks a string into sequential pieces each of which wraps to ≤ `maxLines` within a target width at a given font, splitting ONLY at meaningful **per-locale boundaries** (sentence → clause → word, the highest present that yields a fit) via `Intl.Segmenter` — so a long caption breaks at real sentence/clause points, not a `length×0.52` char-count guess (the estimate the 0.67 measurer-fail-loud work killed). Operates on original-string slices so the re-join is exact and locale-agnostic (never a `' '.join` that would fabricate spaces into zh). Throws the new `TextFitError` (naming the unsplittable token + reword-first fixes) when a single word can't fit even alone, and — because the fit is a cross-consumer promise the render must honor — resolves a real measurer through the 0.67 `resolveMeasurer` chokepoint (fail-loud without one; `{ estimate: true }` is a loudly-caveated escape hatch whose describe() summary warns it may overflow at render, distinct from `splitText`'s benign opt-in). Surfaced on `window.glissade` + as a describe() helper. `narrate`'s `captionAutoSplit` wraps it for timed caption cues. Determinism-safe (build-time, off the render/cert hash; existing goldens byte-identical).
