Why it's not a CSS toy

Three moats no CSS animation has.

A framework earns "serious engineering" by being reproducible and faithfully exportable — not by looking smooth. Here are the three, each demonstrated on this page.

01 · No build

One script tag. The whole authoring surface.

This entire page is a single <script src=…glissade.browser.js> off a pinned CDN — no toolchain, no bundler, no server. window.glissade carries 220+ names: the nodes, the timeline, mount, the Canvas2D backend — and the whole verification surface below (validateScene / critique / diff, composed by assess() into the one closed author→verify→fix loop of 0.63).

03 · Exports without lying

Faithful interchange — or a loud warning.

The same scene is a live browser animation, a byte-exact Skia MP4, and a Lottie file that reimports pixel-faithful. Where a render-only effect can't survive the round-trip, glissade warns — it never silently drops motion.

29 / 47 round-trip ≥ 0.98 SSIM 22 warn about a render-only element 0 silent drops

29 / 47 scenes round-trip to Lottie at ≥ 0.98 SSIM — the showable features (camera, kinetic, particles, gradient bloom, chart, splitText) all at ~1.0000. 22 scenes warn about a render-only element they can't carry (a colored caret, an animated mesh, a blur smear, a variable-font axis) — several of those still round-trip ≥ 0.98; the warning is about the specific dropped element, not the whole scene. 0 silent drops, audited on 0.61.0 — and as of 0.61 that audit is machine-emitted: gs parity --semantic attributes every SSIM residual to a named LOTTIE_DROP / LOTTIE_APPROXIMATE warning, and an UNEXPLAINED_RESIDUAL with no matching warn is a hard error (the never-silent teeth). The render-only elements it drops:

  • mesh: animation is flattened to a static raster — motion dropped.
  • motionBlur: the analog-shutter smear is render-only — the round-trip shows the un-blurred shape.
  • echo: the ghost trails are render-only — only the base shape exports, no copies.
  • variable font: axes have no Lottie text-document field — dropped.

Every render-only feature that can't survive export WARNS. Zero silent drops.

How little code

Animation is data, not code.

A track is a keyframe list. A formula is a pure function of the playhead. No generators, no promise-chained sequencing — the fluent builder compiles to a serializable document.

// a whole ambient particle field — one preset call const { node, tracks } = g.drift({ box: { w: 640, h: 360 }, duration: 3, fps: 60, origin: [0.5, 0.92], area: { kind: 'box', w: 260, h: 60 }, count: 28, rate: 10, color: '#ffcf7a', seed: 9, }); // node → real, exportable layers · tracks → ordinary keyframes

drift() → a seeded, baked emitter. Every mote is a real layer.

// motion as a formula of t — no keyframes at all tl.tracks = orbs.flatMap((o) => [ g.exprTrack(`${o.id}/position.x`, `320 + 220*sin(t*${o.ax})`), g.exprTrack(`${o.id}/position.y`, `180 + 120*cos(t*${o.ay})`), g.exprTrack(`${o.id}/radius`, `24 + 14*sin(t*3)`), ]); // binds through the SAME playhead channel as keyframes

exprTrack() → a whitelist of pure math over the playhead. Lissajous orbits, zero state.

// a radial data-viz gauge — spec in, nodes out const gauge = g.Gauge({ id: 'g', radius: 120, thickness: 20, position: [320, 250], zones: [ { extent: [-90, -30], color: '#e6a700', label: 'BLIND' }, { extent: [-30, 30], color: '#3ddc97', label: 'CALIBRATED' }, { extent: [30, 90], color: '#ff5d73', label: 'RAGE' }, ], }); // fans a spec → zones + ticks + a needle + labels

Gauge() → a build-time fan-out. The needle is one scripted rotation track.

Fails loud, reads itself

Errors name the value and the fix.

A deterministic framework can't afford a silent NaN. Every guard points at the offending value and the correction — never a blank frame three scenes later.

ParticleError: count 500 exceeds max 200 — pass a smaller pool, or raise the cap explicitly.
CameraError: safeBottom must be a RELATIVE fraction in [0,1] (got 907) — did you pass a captionTop in px?
BindError: track 'bar/height' targets a number, but the bound field is a vec2 — check the prop path.

0.59

Fail-loud, before a single frame renders.

validateScene(scene, timeline) → { hasErrors, diagnostics[] }

validateScene is the eager pre-render pass: it walks every track target against the scene graph and aggregates every problem (never throw-on-first) as structured diagnostics — an unknown target, an id collision, a Yoga-positioned child. Below: a track with a typo'd id, caught with the nearest-name fix baked in.

// a track pointed at a node that doesn't exist tl.tracks = [ g.track('bart/height', 'number', [ky(0, 0), ky(1, 120)]) ]; const { hasErrors, diagnostics } = g.validateScene(scene, tl);
UNKNOWN_TARGET track targets 'bart/height' but no node 'bart' exists in the scene — did you mean 'bar'?

0.60

Rendered diagnostics — what's actually wrong on-screen.

critique(scene, timeline) → { diagnostics[], sampledFrames }

critique is the other half: it evaluates the scene across an integer-frame grid and reports rendered-geometry defects a static pass can't see — a node off-canvas its whole life, text overflowing its own box, a layer fully occluded — each with an actionable fix-hint. Below is a deliberately-broken scene (stray-badge pushed off the right edge, a headline too long for its box), critiqued live:

// a badge shoved off-frame + a headline that won't fit its box new R({ id: 'stray-badge', width: 90, height: 40, position: [900, 60] }), new T({ id: 'headline', text: 'far too long for its narrow box', width: 150, box: { valign: 'center', h: 36 } }), const report = g.critique(scene, timeline); // → machine-readable diagnostics

What changed in an edit · what's lost on export.

diff(a, b) → ChangeSet · gs parity --semantic → diagnostics[]

diff(a, b) is the edit-verifier: a construction-order-independent semantic tree-diff that returns a typed ChangeSet, so an agent asserts diff == exactly my intended change-set instead of eyeballing pixels. Two scenes differing by one fill and one added node:

// scene B recolors 'bar' and adds a 'label' const changes = g.diff({ scene: a, timeline: t }, { scene: b, timeline: t });
changes = { added: [ { node: 'label', type: 'Text' } ], removed: [], changed: [ { op: 'changed', node: 'bar', property: 'fill', from: '#39e0ff', to: '#ff5d73' } ], empty: false }
